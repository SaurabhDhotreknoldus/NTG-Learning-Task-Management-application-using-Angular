Assignment 2 Architecture & Ecosystem Demonstrated

Verification matrix for Forms, Routing, Services, and Dependency Injection

Angular Reactive Forms

FormBuilder, FormGroup, custom controls for title, priority, and completed status. Validation rules: required, minLength(3), maxLength(100) with real-time error alerts and Clear Form functionality.

Angular Router & Navigation

Configured routes: /tasks (Task List), /add-task (Add Task Form), and wildcards. Navigation via routerLink, routerLinkActive="active", and programmatic redirect with Router.navigate(['/tasks']) upon form submission.

Dedicated Task Service

Centralized reactive store managing task retrieval, additions with priority & completed status, status updates, deletions, and localStorage persistence via Angular Signals.

Dependency Injection

Provided at root and cleanly injected into TaskListComponent and TaskFormComponent using modern inject(TaskService), decoupling views from data management.
